# ICU in-hospital mortality risk — research prototype

Final-year project demo. **Not a medical device; not for clinical use.**
Trained on the open PhysioNet/CinC Challenge 2012 ICU dataset (first 24 h of data). Silva I, Moody G, Scott DJ, Celi LA, Mark RG. Comput Cardiol 2012;39:245-248.

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`.
